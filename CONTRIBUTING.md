# Разработка пакета

## Требования

Для разработки и сборки нужен Node.js ≥ 24.11.0 в ветке 24 либо ≥ 26.

## Сборка и проверки

- `npm run typecheck` — проверка типов без генерации файлов.
- `npm run build` — проверка типов и сборка ESM и деклараций типов через tsdown в `dist`.
- `npm run lint` — проверка кода ESLint.

Пакет экспортирует основной конфиг и отдельные конфиги через `@storytw/eslint-config/configs`.

## Упаковка и публикация

Перед `npm pack` и `npm publish` скрипт `prepack` автоматически запускает сборку.
Если сборка завершается с ошибкой, упаковка или публикация останавливается.

`npm pack --dry-run` позволяет проверить состав пакета без публикации.
